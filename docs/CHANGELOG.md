# QIpMsg 变更日志

## 2.53.19 — 2026-10-26

飞秋从副网卡发来文件时，TCP 文件口可能开在同一台机器的另一个地址上。连接失败后会改试已知地址。接收进度定时器改在界面线程里跑。

### yy

- 收到文件附件后先连接 UDP 源地址和报文里的端口。连接失败、超时，或连上后还没收到任何文件字节就被关掉时，再试同一登录名、主机和组的其它联系人地址，以及广播列表里的单个 IPv4。与这些地址同一 /24 的优先。不展开网段或 CIDR。最多四个地址。已经开始收到数据后不再换地址。同一批文件会记住这次连上的地址

### zz

- 接收进度定时器原来在接收线程里启动和停止，Qt 提示 Timers cannot be started from another thread，进度也不刷新。现在由会话窗口在界面线程启动，结束、失败或取消时停止；若仍从别的线程调用，则排队到定时器所在线程
- 更新 README、ROADMAP、BUILD，说明多网卡收文件会改试已知地址。只知道 ZeroTier、广播列表里又没有局域网单播地址时，飞秋仍可能关掉连接
- Windows 上刚关闭的独占监听端口会短暂仍显示占用。端口自检在关闭后约两秒内重试探测，仍失败时打印 UDP 和 TCP 的错误，避免 qipmsgPortCheck 偶发报 released.ok / again.ok 失败

### yy

- 偏好设置「文件」和传送窗口可设置对外发送限速（KB/秒，0 为不限），写入 qipmsg.ini。TCP 文件发送按该上限节流，多个发送共用这一额度
- 托盘和偏好设置「文件」可把 `~/.qipmsg` 里的偏好、联系人、历史、表情、组权限、最近联系人、续传、讨论组、离线队列和本地头像导出为未压缩 zip，或从这种 zip 还原。还原前会警告覆盖，完成后提示重新启动。已接收文件和截图不包含在内。不用 Qt Sql
- 全屏或区域截图后可先用画笔、矩形、箭头、文字和撤销做标注，再按原来的 PNG 附件发送。Ctrl+Shift+S / Ctrl+Shift+A 仍然发起截图
- 可为自己或某个 IP 设置本地 PNG/JPEG 头像，显示在联系人列表和会话顶栏，文件放在 `avatars/`。没有飞秋头像协议，对方仍看到色块，除非对方也用 qipmsg 并设置了同一张本地图片
- 成功收发的普通文件按大小和 SHA-256 写入 `~/.qipmsg/filehash.json`（最多 2000 条，先丢掉已不存在的文件）。qipmsg 对端若已有相同内容，用私有命令 126 跳过整段 TCP，会话注明秒传。文件夹不秒传。飞秋文件列表不加哈希字段，仍整文件传输；原有断点续传不变。索引进私人数据 zip
- 偏好设置「文件」可打开一个共享目录，并可设简单密码。联系人显示「享」。会话「浏览对方共享」在原文件端口上列出并下载，路径不能跳出该目录。只对宣告了 qipmsg 共享的对端连接。飞秋共享报文没有核对过的格式，不能浏览飞秋共享
- 偏好设置「详细」可选浅色、暗色或跟随系统，写入 qipmsg.ini。暗色沿用 2.4 布局。已打开的会话气泡要重新打开才按新颜色重画
- 偏好设置可打开「对方有公钥时加密消息」（默认关闭）。本机生成 RSA-1024，私钥写在 `rsa_private.json`。开启后在线包才带 ENCRYPTOPT，并应答 GETPUBKEY。已公布公钥的对端，纯文本用 RSA 封装 AES-256 或 Blowfish-128（IV 为 0）。气泡标明已加密。附件和没有公钥的对端仍发明文。飞秋与官方 IPMsg 的封装未核对
- 离线队列用原子写入保存 `offline_queue.json`，重启后仍在。启动后以及对方上线时投递；发送线程不可用时不丢弃。登录名和主机都非空且只有一个在线匹配时改投新 IP。窗口抖动可以入队。文件不入队，并提示原因。主窗口顶栏和队列窗口显示条数
- Windows 可用 NSIS 把 windeployqt 目录打成当前用户安装包。脚本在 `packaging/qipmsg.nsi`，版本由命令行传入。GitHub Actions 的 Windows 任务上传安装包
- 会话输入可加粗、斜体、下划线，以及小号/大号和五种颜色。发出去的 SENDMSG 正文始终是纯文本，飞秋只看到这段文字。qipmsg 对端在未加密、未密封时另收私有命令 126，正文为 `RICH:<包号>:<安全 HTML 的 base64>`。粘贴会去掉脚本、样式和 RTF/OLE，不会把二进制当唯一正文。加密、密信和离线队列只保留纯文本。本机历史可另记 `rh`
- 区域截图的选区会贴近视窗边框（Windows 枚举顶层窗口；Linux 运行时尝试 `libX11.so.6`，失败则只贴屏幕边；macOS 尽量用窗口列表）。按住 Alt（macOS 为 Option）暂时关闭吸附。截完后的画笔、矩形、箭头和文字标注不变
- 讨论组可设置、修改或清除群公告，写在 `~/.qipmsg/discussions.json`（最多 400 字，空则不写该字段、顶栏也不显示）。变更后用原来的 SENDMSG 发给在线或离开的成员，多于一人时带 MULTICASTOPT。灰色离线不入队。这不是飞秋组播聊天室
- 偏好设置「详细」可导入或选择 `~/.qipmsg/skins/` 下的用户皮肤（目录或 zip）。`skin.json` 给出名称、浅色或暗色底、颜色和可选背景图，`theme.qss` 追加在内置样式之后。QSS 打不开、括号不平衡，或含有 `url` / `@import` 时忽略这份 QSS，仍用内置浅色或暗色。选择记在 `[Appearance] theme`，形如 `skin:名称`。不用 Qt Sql
- 偏好设置「网络」可选定一块网卡。保存其 MAC 作为接口标识（没有 MAC 时保存接口名），并绑定该网卡当前的 IPv4。任意 IPv4 时每块网卡仍参与发现。选定后只在这块网卡上发现；网卡不在线时不会改用其它网卡。Linux 再尝试 SO_BINDTODEVICE（权限不够时仍保留 IPv4 绑定），macOS 使用 IP_BOUND_IF，Windows 使用 IP_UNICAST_IF。系统不能把套接字直接绑到 MAC
- 讨论组可指定本机文件夹，写在 `discussions.json` 的 `sharePath`。窗口列出文件名，「告诉大家」用原来的 SENDMSG 把名单和 `QIPSHARE:<组标识>` 发给在线成员。成员在单聊里点「讨论组文件夹」，用命令 126 的 GLIST/GGET 只读取群主的该目录。个人共享的 LIST/GET 不变。对方必须在线且是 qipmsg。这不是飞秋组播聊天室，也不用 Qt Sql
- qipmsg 之间可交换小头像。在线包第四段在原有 `qipmsg` 记号后追加 `,av:<12 位摘要>`，对端用文件端口上的命令 126、动词 AVATAR 取回最多 96 KB 的 PNG，存到 `avatars/wire/`。本机手动设置的头像优先。飞秋和经典飞鸽没有可核对的头像命令，版本号仍为 1，不会把照片当成文件附件弹出接收框；对方资料里写明仍是色块。清除仅有的取回头像后，在对方公布另一张之前不再拉取
- 讨论组可记本地群日志，追加写入 `~/.qipmsg/grouplog/<组标识>.jsonl`（不用 Qt Sql，单文件约 2 MB 后拒绝再写）。窗口可查看并导出 txt 或 jsonl。勾选「告诉在线成员」时，用原来的 SENDMSG 发一条纯文本，离线不入队。这不是飞秋群日志协议
- 单聊工具栏「涂鸦」可用画笔、四种颜色和清除画一张图，导出 PNG 后走现有图片附件发送。不需要数位板压感
- 主窗口和托盘可新建、修改、删除本机定时提醒，写在 `~/.qipmsg/schedule.json`（不用 Qt Sql，最多 200 条）。到点时弹出托盘通知；未关闭消息提示音时播放原来的提示音。程序退出后没有后台服务；退出期间错过的时间，下次启动补响一次。勾选通知对方时，按普通 SENDMSG 发出文字，对方离线则走现有离线队列。没有飞秋时钟报文
- 单聊工具栏「收藏」可把选中的聊天文字、本机文件路径或对该好友的备注写入 `~/.qipmsg/favorites.json`（不用 Qt Sql，最多 300 条）。可搜索、打开和删除。文件用系统程序打开。不同步，也不自动发给对方
- 联系人里带 `IPMSG_DIALUPOPT` 的好友显示「拨号」和橙色标记。本机广播在线、离开或退出时，再向这些好友单播同一条成员识别，因为拨号链路可能收不到子网广播。收到对方入网仍只回原来的 ANSENTRY，避免两台拨号 qipmsg 对撞。偏好「我是拨号主机」默认关闭，打开后自己的在线包带上该位。没有该位的普通局域网好友保持原样。标记记在 `peers.json`。飞秋自己的拨号图标没有逐包核对
- Windows 上可从联系人右键或会话资料卡打开 `\\IPv4\`。系统负责询问共享密码，本程序不收集凭据。其它系统上该动作仍显示，但是禁用，并说明只在 Windows 可用。只接受没有前导零的普通 IPv4，不接受 `0.0.0.0` 和组播地址
- 已经在运行的 qipmsg 监听当前用户的本地套接字（Windows 上是命名管道），不监听 TCP。另一进程可用 `qipmsg --msg <IPv4 或 登录名@主机> --text <文字>` 发一条普通 SENDMSG，走原来的发送路径，包括加密偏好；已知离线且离线队列开着时入队。程序没在运行时命令退出，不会再开一个窗口。这不是插件市场
- 会话工具栏「空间」和「日志」打开 `~/.qipmsg/zone/` 里的 Markdown 或文本笔记，目录不存在会创建。可新建、修改、删除，并打开该文件夹。这不是飞秋 `zone/*.db` 博客，也不会发给对方。私人数据 zip 会带上 `zone/`。远程协助、远程控制和语音仍是禁用占位
- 启动时默认打开联系人主窗口，托盘菜单第一项是「打开主窗口」。系统没有通知区域，或图标没有显示出来时，也会打开主窗口。偏好「启动时只留在通知区域」默认关闭；关掉主窗口后，通知区域可用时程序仍留在托盘。勾选该项且图标可见时才只进托盘，并提示一次如何打开主窗口
- UDP 和 TCP 文件端口在启动时检查。被占用、系统拒绝（Windows 上会尽量对照 `netsh interface ipv4 show excludedportrange`）或地址不可用时说明原因，并可把一个空闲端口写入 `udpPort` 后立即重试。默认仍用 2425，只有同意才改。若因此离开了 2425，下次 2425 空闲时会询问是否改回。关闭对话框不会退出，联系人窗口保持打开
- 会话工具栏分成「传输」和「聊天」，按钮为图标加文字。发送文件、发送文件夹、截图、表情、抖动和查找仍一次点到。浏览对方共享、讨论组文件夹、涂鸦、收藏、空间和日志收进「更多」。远程协助、远程控制和语音仍禁用，只放在「更多」里，不占主栏
- 顶栏「资料」可收起或展开对方资料，默认展开。收起后窗口变窄。窗口宽高、是否最大化，以及资料栏开关记在 `qipmsg.ini` 的 `ChatWindow`，下次打开任意会话沿用。不用 Qt Sql

- 修复 Qt6 下 `class QStringList` 前向声明与 `QByteArray::append(QString)` 无法编译
- 文件创建时间改为 `QFileInfo::birthTime()`，避免 Qt6 移除 `created()`
