# QIpMsg 变更日志

## 2.30.6 — 2026-10-25

发送限速、私人数据备份与还原、截图基础标注，以及仅保存在本机的自定义头像。同日再补已传文件秒传、qipmsg 共享目录，以及浅色/暗色主题。

### yy

- 偏好设置「文件」和传送窗口可设置对外发送限速（KB/秒，0 为不限），写入 qipmsg.ini。TCP 文件发送按该上限节流，多个发送共用这一额度
- 托盘和偏好设置「文件」可把 `~/.qipmsg` 里的偏好、联系人、历史、表情、组权限、最近联系人、续传、讨论组、离线队列和本地头像导出为未压缩 zip，或从这种 zip 还原。还原前会警告覆盖，完成后提示重新启动。已接收文件和截图不包含在内。不用 Qt Sql
- 全屏或区域截图后可先用画笔、矩形、箭头、文字和撤销做标注，再按原来的 PNG 附件发送。Ctrl+Shift+S / Ctrl+Shift+A 仍然发起截图
- 可为自己或某个 IP 设置本地 PNG/JPEG 头像，显示在联系人列表和会话顶栏，文件放在 `avatars/`。没有飞秋头像协议，对方仍看到色块，除非对方也用 qipmsg 并设置了同一张本地图片
- 成功收发的普通文件按大小和 SHA-256 写入 `~/.qipmsg/filehash.json`（最多 2000 条，先丢掉已不存在的文件）。qipmsg 对端若已有相同内容，用私有命令 126 跳过整段 TCP，会话注明秒传。文件夹不秒传。飞秋文件列表不加哈希字段，仍整文件传输；原有断点续传不变。索引进私人数据 zip
- 偏好设置「文件」可打开一个共享目录，并可设简单密码。联系人显示「享」。会话「浏览对方共享」在原文件端口上列出并下载，路径不能跳出该目录。只对宣告了 qipmsg 共享的对端连接。飞秋共享报文没有核对过的格式，不能浏览飞秋共享
- 偏好设置「详细」可选浅色、暗色或跟随系统，写入 qipmsg.ini。暗色沿用 2.4 布局。已打开的会话气泡要重新打开才按新颜色重画

### zz

- 更新 README、ROADMAP、BUILD 与 zh_CN，说明限速、备份范围、截图标注和本地头像不会出现在线上
- 更新 README、ROADMAP、BUILD 与 zh_CN，说明秒传和共享只在 qipmsg 之间生效，飞秋仍需人工回归

## 2.19.3 — 2026-10-24

托盘与日常设置四项：开机自启、勿扰、上下线提示音、已读回执。默认都不强行打开（自启与提示音默认关，勿扰默认关）。

同日再补部门组权限和自定义表情：按组隐身、屏蔽组消息、可导入的 GIF/图片表情，以及表情分组。

### yy
- 偏好设置可选择开机自启，默认关闭。Windows 写入当前用户 Run 键，Linux 写入 XDG autostart，macOS 写入用户 LaunchAgent，下次登录生效，不改飞秋自己的启动项
- 托盘与偏好设置增加独立勿扰：不弹托盘气泡、不自动升起会话窗口；消息仍进历史和未读，离开/自动回复不受影响
- 可单独打开上下线提示音。启动后数秒内不响，同一对端 20 秒内只响一次，短时间一批上下线合并成一声
- 收到 `READMSG` 时，发送方会话气泡显示「已读」。开封路径仍按原来的 `READMSG` 回执，不新增私有线缆格式
- 可对指定部门组隐身：不回复该组的 `ANSENTRY`，并单播 `BR_EXIT`；只要还有隐身组，周期性在线改为向其他已知好友单播，不再向子网广播。名单写入 `group_policy.json`
- 可屏蔽指定部门组的消息提醒：历史和未读仍在，不弹会话、不响铃、不显示托盘气泡。与勿扰、按组隐身互相独立
- 聊天表情面板可导入 PNG、GIF、WebP、JPEG，文件放在 `stickers/`，点击后按现有图片附件发送
- 自定义表情可分成命名分组，索引在 `stickers.json`。内置 Unicode 仍为单独的「经典」组

### zz
- 更新 README、ROADMAP、BUILD 与 zh_CN，说明如何试用这四项设置
- 更新 README、ROADMAP、BUILD 与 zh_CN，说明按组隐身的协议限制、组消息屏蔽，以及自定义表情和分组的本地存储

#### 编译
- 使用 QLockFile 替代 POSIX flock/fcntl，修复 Windows MinGW 下 S_IRUSR、struct flock、F_SETLK 无法编译
- 使用 QThread::msleep 替代 usleep，去掉对 unistd.h 的依赖
- 文件发送套接字改为 Winsock/POSIX 条件编译，避免 sys/socket.h 在 Windows 下失败
- incomingConnection 与发送线程套接字描述符改为 qintptr，避免 Win64 句柄截断
- 接收文件时间戳在 Windows 下改用 sys/utime.h
- helper.cpp 的 endl 改为 Qt::endl
- 修复 Qt6 下 `class QStringList` 前向声明与 `QByteArray::append(QString)` 无法编译
- 文件创建时间改为 `QFileInfo::birthTime()`，避免 Qt6 移除 `created()`

#### 注释
- 补充飞秋向能力的 ROADMAP 完成项与后续范围说明
- 将 2.2.0 本轮能力标为完成，表情/插件/文件共享/群聊/语音/加密/换肤/NSIS 仍延后
- 说明界面默认简体中文，zh_CN 目录随程序资源加载
