# QIpMsg

QIpMsg 是 Linux / Windows / macOS 下的 IP Messenger（飞鸽传书）客户端，兼容飞秋（Feiqiu / FeiQ）等同类局域网通讯工具。

当前版本：**2.1.0**

## 特性

- 局域网用户发现（昵称 / 分组/部门 / 主机 / IP / 在线状态）
- 周期性在线刷新（飞秋 AutoRefresh）与过期用户灰色/移除
- 按对端复用的持久聊天窗口，本地消息历史
- 单聊与多选群发
- 文件 / 文件夹传输与进度显示
- 系统托盘、未读计数与气泡通知
- 离开 / 自动回复（冷却、BR_ABSENCE）
- GBK 默认传输编码，可切换 UTF-8；解码失败时回退

## 试用 2.1.0

1. 启动后用户列表按「自动刷新」间隔广播 `BR_ENTRY`（离开时为 `BR_ABSENCE`）。超时未应答的用户变灰，随后移除。
2. 在用户列表中**双击**某用户（或右键「打开会话」）打开持久聊天窗口。关闭后再打开会从 `~/.qipmsg/history/`（Windows：`%USERPROFILE%\.qipmsg\history\`）载入记录。`Ctrl+Enter` 发送。
3. 托盘「设置」→「详细/记录」：刷新间隔、过期次数、托盘通知、传输编码（默认 GBK，可改 UTF-8）。
4. 托盘「离开 → 离开/自动回复」，或在偏好设置中填写回复内容与冷却秒数。收到普通消息时按对端冷却自动回复一次。
5. 新文本消息会弹出托盘提示；工具提示显示「用户数 + 未读数」。单击托盘可唤起未读会话。

密信与带附件的消息仍走原来的接收窗口；打开密信后文本会写入对应会话历史。截图、公钥加密、自定义表情、断点续传数据库等见 [ROADMAP.md](../ROADMAP.md)。
