# QIpMsg

[![Build](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml/badge.svg)](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml)

QIpMsg 是 Linux / Windows / macOS 下的 IP Messenger（飞鸽传书）客户端，兼容飞秋（Feiqiu / FeiQ）等同类局域网通讯工具。

当前版本：**2.7.0**

## 特性

- 局域网用户发现（昵称 / 分组/部门 / 主机 / IP / 在线状态 / 签名提示）
- 周期性在线刷新（飞秋 AutoRefresh）；上次用户灰色离线直至再次上线
- 按对端复用的持久聊天窗口，本地消息历史与全局查找
- 单聊与多选群发
- 文件 / 文件夹传输、目录进度、普通文件断点续传（飞秋 2013 / IPMSG TCP 十进制或十六进制命令）
- 大于 4GB 的文件：线缆允许处使用 64 位大小/偏移，续传与进度不截断
- 可配置 UDP 监听端口与网卡绑定（默认 2425 / 任意 IPv4，绑定失败软失败）
- 自动接收、默认保存目录、重名改名；聊天窗口拖放附件
- 窗口抖动、截图发送
- 系统托盘、未读计数与气泡通知
- 离开 / 自动回复（冷却、BR_ABSENCE）
- GBK 默认传输编码，可切换 UTF-8；解码失败时回退
- 界面默认简体中文（嵌入 `qipmsg_zh_CN.qm`；中文系统语言优先，其它环境回退中文）
- 现代浅色会话界面（WeChat / Slack-lite / Fluent）：主窗口头像与搜索、圆角联系人、聊天气泡、对方资料卡片
- 飞秋式联系人树（分组、搜索、个性签名、在线数、黑名单）与会话对方资料

## 试用 2.7.0

1. 启动后为简体中文浅色界面。主窗口顶部是自己的圆角头像、昵称、在线状态与个性签名；联系人按「我的好友 / 对方未分组好友 / 部门组 / 自己 / 黑名单」分组。灰色用户来自 `~/.qipmsg/peers.json`，上线后恢复颜色。
2. 顶部「搜索好友」过滤列表。双击或右键「打开会话」进入聊天。右键可加入/移出黑名单。
3. 会话为气泡卡片：左侧收到、右侧发出。工具栏：发送文件/文件夹、窗口抖动、截图、查找；远程/语音/共享/空间仍禁用，悬停提示「暂未实现」。右侧对方资料显示头像、状态、签名与主机/登录/分组/IP。
4. 托盘或会话「查找历史」搜索全部 `history/*.jsonl`。
5. 托盘「设置」→「详细」→「文件」：续传、自动接收、重名改名、默认接收目录。同页「网络」可改 UDP/TCP 监听端口与绑定网卡（更改后需重启）。昵称框可填个人签名。
6. 托盘「离开 → 离开/自动回复」，或在偏好设置中填写回复内容与冷却秒数。收到普通消息时按对端冷却自动回复一次（抖动消息不自动回复）。
7. 新文本消息会弹出托盘提示；工具提示显示「用户数 + 未读数」。单击托盘可唤起未读会话。

密信与带附件的消息仍走原来的接收窗口；打开密信后文本会写入对应会话历史。自定义表情、插件、文件共享服务、群聊、语音、公钥加密、换肤、NSIS 打包等见 [ROADMAP.md](../ROADMAP.md)。
