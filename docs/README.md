# QIpMsg

[![Build](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml/badge.svg)](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml)

QIpMsg 是 Linux / Windows / macOS 下的 IP Messenger（飞鸽传书）客户端，兼容飞秋（Feiqiu / FeiQ）等同类局域网通讯工具。

当前版本：**2.53.18**

2.53.18 收飞秋文件时，若 UDP 来自副网卡而 TCP 文件口开在另一个已知地址，会在连接失败后再试。例如 UDP 源是 192.168.14.164、文件口实际在 192.168.14.3，且 .3 写在广播列表里，或联系人里还有同一登录名、主机和组的地址。先连 UDP 源，失败后再试，最多四个。已经收到数据后不换地址。进度定时器只在界面线程跑。只剩 ZeroTier、又没有对应局域网地址时仍可能失败。飞秋界面仍需人工对照。

2.52.16 把会话工具栏收成「传输」「聊天」和「更多」。发送文件、发送文件夹、截图、表情、抖动和查找仍在栏上一次点到；浏览共享、讨论组文件夹、涂鸦、收藏、空间和日志在「更多」里。远程协助、远程控制和语音仍是「更多」中的禁用项。顶栏「资料」可收起对方资料。窗口宽高和资料栏开关记在 `qipmsg.ini` 的 `ChatWindow`。飞秋界面仍需人工对照。

2.50.15 启动后会打开联系人主窗口，避免只停在通知区域里找不到图标。若 UDP/TCP 端口（默认 2425）被占用或被系统拒绝，会说明原因，并可改用一个空闲端口写入 qipmsg.ini 后立即重试。2425 空闲时仍优先使用它。

2.48.14 可在 Windows 上打开好友的网上邻居（`\\IP\`，密码由系统询问）。已经运行的程序接受本机命令 `qipmsg --msg <地址或登录名@主机> --text <文字>`，发出一条普通消息。会话里的「空间」和「日志」打开 `~/.qipmsg/zone/` 的本地笔记，不是飞秋空间数据库。远程协助、远程控制和语音仍未实现。飞秋界面仍需人工对照。

## 特性

- 局域网用户发现（昵称 / 分组/部门 / 主机 / IP / 在线状态 / 签名提示）
- 周期性在线刷新（飞秋 AutoRefresh）；上次用户灰色离线直至再次上线
- 按对端复用的持久聊天窗口，本地消息历史与全局查找
- 会话工具栏按「传输 / 聊天 / 更多」归类。常用的发送文件、发送文件夹、截图、表情、抖动、查找一次点到；其余收进「更多」。对方资料可收起，窗口大小会记住
- 单聊与多选群发
- 本地讨论组（多选联系人命名保存，同一文本群发给各成员；非飞秋组播群协议）
- 文件 / 文件夹传输、目录进度、普通文件断点续传（飞秋 2013 / IPMSG TCP 十进制或十六进制命令）
- 大于 4GB 的文件：线缆允许处使用 64 位大小/偏移，续传与进度不截断
- 可配置 UDP 监听端口与网卡绑定（默认 2425 / 任意 IPv4；打不开时说明原因并可改用空闲端口，绑定仍失败则软失败）
- 启动后打开联系人主窗口（偏好里可改回只进通知区域）
- 自动接收、默认保存目录、重名改名；聊天窗口拖放附件
- 窗口抖动、截图发送；会话气泡内联图片预览（点击打开原图）
- 工具栏基础 Unicode 表情包；飞秋 `/微笑` 一类口令在本端渲染为表情
- 系统托盘、未读计数与气泡通知
- 本机日程提醒（主窗口与托盘；`schedule.json`；仅在程序运行时响起，退出后无后台服务）
- 会话收藏夹（选中文字、文件路径或好友备注；`favorites.json`；可搜索、打开、删除；不同步）
- 拨号主机：识别 `IPMSG_DIALUPOPT`，联系人单独标记，并在在线刷新时单播成员识别；偏好可声明自己是拨号主机
- Windows 网上邻居：联系人右键或会话资料卡打开 `\\IPv4\`。非 Windows 上该动作禁用。不自做共享登录框
- 本机命令：`qipmsg --msg <IPv4 或 登录名@主机> --text <文字>` 把一条纯文本交给正在运行的 qipmsg 发送。不是插件，也不开网络端口
- 本地空间 / 日志：`~/.qipmsg/zone/` 下的 Markdown 和文本笔记，可新建、打开、删除。不是飞秋 `zone/*.db`
- 开机自启（默认关闭；Windows 当前用户、Linux XDG、macOS 登录项）
- 勿扰：不弹消息窗、不弹托盘气泡，历史和未读仍在（与离开/自动回复分开）
- 上下线提示音（默认关闭，启动后静音数秒，并对抖动限流）
- 已读回执：对方打开需回执的消息后，本端气泡显示已读
- 离开 / 自动回复（冷却、BR_ABSENCE）
- 本地备注昵称（`peers.json` 的 `memo`，树与会话标题用备注，资料卡保留真名）
- 联系人搜索支持拼音首字母与常见字全拼
- 隐身 / 隐藏模式（不回复发现，托盘可切换；无服务器，尽力而为）
- 按部门组隐身，以及屏蔽该组的消息提醒（`group_policy.json`；隐身是尽力而为的 IPMSG，不是飞秋私有扩展）
- 自定义表情：可导入 PNG / GIF / WebP / JPEG，按图片附件发送，并可在本地分组（`stickers.json`）
- 离线消息队列（`offline_queue.json`，重启后仍在；对方上线后按序发送文字和窗口抖动；附件不入队）
- 可选公钥加密（默认关闭）：对方公布公钥后，纯文本用 RSA 加 AES-256 或 Blowfish 密封。附件和经典飞秋仍走明文。飞秋/官方 IPMsg 的封装未核对
- GBK 默认传输编码；对宣告 `CAPUTF8OPT` 的对端改用 UTF-8，并在入网包宣告 UTF-8 / 剪贴板能力
- 跨网段 IPv4 范围或 CIDR 批量加入广播发现列表（单播探测，无中心服务器）
- 全体广播：向当前在线对端发送带 `BROADCASTOPT` 的文本（主窗口与托盘）
- 密信：会话气泡内密封，拆开后才显示正文并回开封确认
- 界面默认简体中文（嵌入 `qipmsg_zh_CN.qm`；中文系统语言优先，其它环境回退中文）
- 现代浅色会话界面（WeChat / Slack-lite / Fluent）：主窗口头像与搜索、圆角联系人、聊天气泡、对方资料卡片
- 飞秋式联系人树（分组、搜索、个性签名、在线数、黑名单）与会话对方资料
- 按部门组群发：只发给该组在线与离开的成员（`IPMSG_MULTICASTOPT`），离线不入队
- 最近联系人（`recent.json`，单击打开会话）
- 正在输入：飞秋命令 121 / 122，版本号仍为 1
- 传送中可取消，并按实测速度显示剩余时间
- 对外文件发送限速（0 为不限，多个发送共用额度）
- 备份 / 还原私人数据（未压缩 zip，不含已接收文件和截图）
- 截图后可做画笔、矩形、箭头、文字标注，再按 PNG 附件发送
- 本地自定义头像；qipmsg 之间还会用命令 126 交换一张小图。飞秋没有可核对的头像报文，仍显示色块
- 讨论组群日志：追加写在 `grouplog/<id>.jsonl`，可在窗口查看和导出。可选把一条纯文本发给在线成员。不是飞秋群协议
- 随手涂鸦：画笔、颜色、清除，导出 PNG 后按现有图片附件发送
- 已传文件秒传：普通文件记入 `filehash.json`（大小 + SHA-256）。qipmsg 对端已有相同内容时跳过 TCP，会话注明秒传。飞秋仍整文件传输
- 共享文件夹：可指定目录和可选密码，联系人显示「享」。会话可浏览对方的 qipmsg 共享并下载。飞秋共享不能列出
- 外观：浅色 / 暗色 / 跟随系统，记在 qipmsg.ini
- 会话输入可加粗、斜体、下划线、字号和颜色。线上正文仍是纯文本；只有 qipmsg 对端会再收到一份安全 HTML。飞秋只看到纯文本
- 区域截图选区可贴近视窗，按住 Alt（macOS 为 Option）暂时关闭
- 讨论组群公告：写在 `discussions.json`，显示在会话顶部，并用原来的群发通知在线成员。空公告不显示
- 用户皮肤：`~/.qipmsg/skins/` 下的文件夹或 zip。浅色、暗色、跟随系统仍然可用。QSS 无效时回退到内置样式
- 网络里可选定一块网卡，并记住它的 MAC（没有 MAC 时记住接口名）。任意 IPv4 时多网卡发现不变
- 讨论组可指定本机文件夹。在线的 qipmsg 成员能按口令只取这个目录里的文件。飞秋看不到可浏览的共享

## 试用 2.53.18

1. 飞秋多网卡时，把飞秋实际监听文件的局域网地址（例如 192.168.14.3）写进偏好设置的广播地址。联系人里若已有同一登录名、主机和组的另一个地址，也会参加候选。
2. 从飞秋发一个小文件给 qipmsg。若 UDP 源是另一块网卡（例如 192.168.14.164）且该地址的 TCP 2425 拒连或超时，qipmsg 会再连 192.168.14.3:2425。日志里有 `RecvFileTransfer: try`，连上备用地址时有 `file port`。
3. 接收过程中，消息窗按钮上的进度应刷新。控制台不应再出现 `Timers cannot be started from another thread`。
4. 若联系人里只有 ZeroTier 地址，且广播列表没有飞秋的局域网单播地址，反向收文件仍可能被飞秋关掉。把局域网地址加进广播列表后再试。网段和 CIDR 不会被当成文件服务器逐个去连。

## 试用 2.52.16

1. 打开一个单聊。顶栏应是「传输」里的发送文件、发送文件夹，以及「聊天」里的截图、表情、抖动、查找，最后是「更多」。窗口不必拉得很宽也能放下这些按钮。发送文件、发送文件夹、表情、抖动、查找点一下就执行。截图点一下弹出全屏或框选。

## 试用 2.50.15

1. 正常启动。应立刻看到联系人主窗口，任务栏里也有 qipmsg。关掉窗口后程序仍留在通知区域；托盘菜单第一项「打开主窗口」可以再打开它。偏好设置「详细」里勾选「启动时只留在通知区域」并保存，重新启动后才只进托盘，并出现一次提示。系统没有通知区域时，即使勾了这一项也会打开主窗口。
2. 让 2425 被占用（先开飞秋，或另有程序监听该端口），或在 Windows 上让 2425 落在排除端口范围里。启动后应弹出说明：占用，或系统拒绝（排除范围会尽量对照 `netsh interface ipv4 show excludedportrange`）。点「改用端口 …」后，`qipmsg.ini` 的 `udpPort` 变成该端口，发现和文件传输都改用它，不必先重启。点关闭或「仍然继续」时，联系人窗口仍在，程序不会只剩托盘。
3. 2425 恢复空闲后再启动。若上次是对话框改走的端口，会询问是否改回 2425。改回后对端仍按飞秋 / IPMSG 的默认端口发现你。关掉该询问会保留当前端口，之后不再每次追问；要改回可到偏好设置「详细」→「网络」。

## 试用 2.48.14

1. 在 Windows 上右键一个好友，选「打开网上邻居」，或在会话资料卡点「网上邻居」。资源管理器应打开 `\\该 IP\`。共享要密码时由 Windows 弹出，qipmsg 不询问。Linux 和 macOS 上同一项是灰的，提示只在 Windows 可用。地址不是普通 IPv4 时不会打开。

3. 会话「更多」里的「空间」或「日志」打开同一个本机笔记窗口。新建一条，保存，关掉再开仍在。文件在 `~/.qipmsg/zone/`，后缀为 md、txt 或 markdown。删除只删这个文件。这不是飞秋的 zone 数据库，也不会同步给对方。远程协助、远程控制、语音在「更多」里仍是灰色的「暂未实现」。

## 试用 2.39.11

1. 把一个皮肤文件夹放进 `~/.qipmsg/skins/Ocean/`，或在偏好设置「详细」里导入文件夹 / zip。`skin.json` 至少要有名字；`base` 取 `light` 或 `dark`；颜色、`theme.qss` 和背景图都可以省略。选中后浅色和暗色仍在列表里。QSS 如果括号不成对，或写了 `url(`、`@import`，会提示并继续用内置样式。已经打开的会话要关掉再开，气泡才用新颜色。
2. 偏好设置「详细」→「网络」不要选「任意 IPv4」，改选一块网卡。重启后 UDP 和文件端口绑在这块网卡当前的 IPv4 上，`qipmsg.ini` 里有 `bindMac` 和 `bindInterfaceId`。另一块网卡上的子网广播不再发出。把选项改回任意 IPv4 后，多网卡发现恢复。Linux 还会尝试把套接字固定到该网卡，权限不够只记日志。macOS 用接口索引，Windows 用 IPv4 和 IP_UNICAST_IF。没有系统能把套接字直接绑到 MAC。
3. 打开讨论组，设置一个本机文件夹。侧栏列出文件名。点「告诉大家」后，在线成员的单聊里会出现名单和一行 `QIPSHARE:`。对方在「更多」里点「讨论组文件夹」即可列出并下载，路径不能跳出这个目录。你离线时对方连不上。飞秋只会看到那段文字，不能浏览。个人共享目录不受影响。这不是飞秋的组播聊天室。

## 试用 2.36.10

1. 在单聊或讨论组输入框上方点 B / I / U，或选字号、颜色。发给飞秋的仍是纯文本，对方应能正常阅读，看不到格式。两台 qipmsg 互发时，对方气泡会按同一套格式重画。从网页粘贴会去掉脚本；RTF 和带 NUL 的内容按纯文本插入。勾选加密或密信时，本机仍可看到格式，对方只收到密封正文，没有 HTML 旁路。离线队列里的待发消息也没有格式。

3. 打开讨论组，点「群公告」。写下文字后保存，顶栏出现公告，在线和离开的成员收到一条普通文本（多人时带 MULTICASTOPT）。留空或点清除后顶栏消失，在线成员收到清除说明。灰色成员不会进离线队列。没有在线成员时只保存在本机。这不是飞秋的组播聊天室。

## 试用 2.33.9

1. 偏好设置「发送/接收」勾选「对方有公钥时加密消息」。第一次会在 `~/.qipmsg/rsa_private.json` 写下私钥，界面可能停顿一下。之后在线包才带 ENCRYPTOPT。两台都打开的 qipmsg 互发纯文本，气泡前有「已加密」。带附件的消息仍是明文。没拿到公钥的飞秋仍收到原来的明文，未知命令应被忽略。飞秋和官方 IPMsg 能否解开这种 RSA 封装没有核对过，需要人工回归；解不开时会话会写明无法解密。
2. 给灰色好友发一条文字和一次窗口抖动，完全退出再打开，托盘「离线消息队列」和主窗口顶栏仍能看到条数。对方以同一登录名和主机名从上线（哪怕 IP 变了，且只有一个匹配）后应按顺序送达。只发文件时会提示文件不入队。
3. Windows 上对 `windeployqt` 目录执行 `makensis -DVERSION=2.33.9 -DDEPLOYDIR=... packaging\qipmsg.nsi`，得到当前用户安装包。GitHub Actions 的 Windows 产物里另有 `qipmsg-windows-setup`。

## 试用 2.30.6

1. 两台 qipmsg 互发同一个普通文件。第一次走 TCP，成功后写入 `~/.qipmsg/filehash.json`（最多约 2000 条）。再发一次时，若接收目录里已有相同大小和 SHA-256 的同名文件，或索引里能找到这份内容，则不再传字节，双方会话出现「秒传」。文件夹不走秒传。飞秋对端的文件列表不加哈希字段，仍然整文件传输；请用真飞秋确认列表形状没有变化。原有断点续传还在。
2. 偏好设置「详细」→「文件」勾选共享，选一个目录，密码可留空。保存后自己的联系人行出现绿色「享」。对方也必须是打开了共享的 qipmsg。会话「更多」里的「浏览对方共享」列出最多 200 项，下载进接收目录。`..` 和越出共享根的路径会被拒绝。对飞秋只提示不能浏览，不会发起连接。
3. 同一设置里「外观」选浅色、暗色或跟随系统。浅色仍是 2.4 主题。已经打开的会话要关掉再开，气泡才按新颜色重画。选择在 `qipmsg.ini` 的 `[Appearance] theme`。跟随系统在 Qt 6.5 及以上读取系统配色，更早的 Qt 用启动时窗口的明暗。

## 试用 2.27.5

1. 偏好设置「详细」→「文件」，或托盘里的传送窗口，把发送限速设为 `256` KB/秒（0 是不限，1024 KB/秒等于 1 MB/秒）。再发一个较大的文件，传送速度应停在这个上限附近。取消传送仍然有效。这个限制只作用在本机对外的 TCP 文件发送上。

## 试用 2.23.4

3. 偏好设置「发送/接收」里「显示我的输入状态」默认勾选。输入时发出命令 121，停约 2 秒或清空/发送后发出 122，不附加其它选项位，版本号仍是 `1`。对方若发来同样的 121/122，会话标题和联系人行会显示「正在输入…」。经典 IPMSG 会忽略未知命令。抓包里的飞秋版本串是 `1_lbt…`，只认该版本串的飞秋可能不显示你的输入状态，需要和真飞秋对一下。

## 试用 2.19.3

1. 右键某个部门组（或该组里的好友），勾选「对组隐身」。偏好设置「发送/接收」里的「组权限」是同一张表。名单写在 `~/.qipmsg/group_policy.json`。该组好友再刷新时不应再看到你的 `ANSENTRY`；你这边仍能看见他们。只要还有任意一组处于隐身，本机就不再向整个子网广播在线，只给已知的其他好友单播。取消全部隐身后，下一次刷新会恢复子网广播。

## 试用 2.15.2

1. 托盘「设置」→「详细」勾选「开机时启动」。默认不勾。Windows 只写当前用户的 Run（名称 QIpMsg），Linux 写 `~/.config/autostart/qipmsg-autostart.desktop`，macOS 写 `~/Library/LaunchAgents/org.qipmsg.login.plist`。下次登录才启动，当前这次不会再拉起一份。取消勾选会删掉上述入口，不会动飞秋自己的启动项。
2. 托盘「勿扰（不弹出消息窗口）」或偏好设置里同一项。打开后新消息不弹托盘气泡、不把会话窗口抬到前面；历史仍写入，未读数和托盘图标闪烁还在。单击托盘仍可自己打开未读会话。这不会广播离开，也不会自动回复。
3. 偏好设置「发送/接收」勾选「好友上线或下线时播放声音」（默认关）。上线用 `info.wav`，下线用 `warning.wav`。刚启动约 8 秒内不响，避免一入网就响成一片；同一地址 20 秒内只响一次，1.5 秒内的一批只留一声。离开与在线之间切换不响，只有真正上下线才响。
4. 会话勾选「封装」发出去。对方点开密封条后会回 `READMSG`（和以前一样）。本端那条气泡下方变成「已读」；若当时没看着这个会话，且仍勾着「检查信封是否被打开」，还会弹出原来的开封提示。勿扰打开时不弹这个提示，但气泡和历史里的已读标记还在。

## 试用 2.11.1

1. 启动后为简体中文浅色界面。主窗口顶部是自己的圆角头像、昵称、在线状态与个性签名；联系人按「我的好友 / 对方未分组好友 / 讨论组 / 部门组 / 自己 / 黑名单」分组。灰色用户来自 `~/.qipmsg/peers.json`，上线后恢复颜色。
2. 顶部「搜索好友 / 拼音」可按昵称、主机、登录名、备注、IP 过滤，并支持拼音首字母（如「张三」→ `zs`）与常见字全拼（如 `zhang`）。右键「设置备注」写入本地备注；树与会话标题显示备注，右侧资料「昵称」仍为对端真名。多选至少两名联系人后右键「创建讨论组」，组名与成员键（user@host/ip）保存在 `~/.qipmsg/discussions.json`。双击讨论组打开本地群发窗口；回复仍走一对一会话。这是本地多发 UX，不是飞秋组播聊天室协议。
3. 会话为气泡卡片：左侧收到、右侧发出。工具栏「传输」为发送文件/文件夹，「聊天」为截图、表情、抖动、查找；浏览共享、涂鸦、收藏、空间和日志在「更多」里。远程协助、远程控制和语音在「更多」中禁用，悬停提示「暂未实现」。顶栏「资料」可收起右侧对方资料（头像、状态、签名、真实昵称与主机/登录/分组/IP）。发送或接收 png/jpg/gif/bmp/webp 后气泡内显示缩略图，点击打开原图。Ctrl+V 可粘贴剪贴板图片为附件。历史 JSONL 可带 `img` 字段。
4. 托盘或会话「查找历史」搜索全部 `history/*.jsonl`。
5. 托盘「设置」→「详细」→「文件」：续传、自动接收、重名改名、默认接收目录。同页「网络」可改 UDP/TCP 监听端口与绑定网卡（更改后需重启）。昵称框可填个人签名。
6. 托盘「离开 → 离开/自动回复」，或在偏好设置中填写回复内容与冷却秒数。收到普通消息时按对端冷却自动回复一次（抖动消息不自动回复）。
7. 托盘「离开 → 隐身/隐藏模式」或偏好设置勾选隐身：本机不再广播 `BR_ENTRY`/`BR_ABSENCE`，也不回复 `ANSENTRY`；进入隐身时先发 `BR_EXIT`。已知道你 IP 的对端仍可发消息（无中心服务器，无法对全网真正隐身）。
8. 对灰色/离线好友发文本或窗口抖动会进入会话「离线队列」（可取消单条或清空），退出重开后还在。对方再次入网后按顺序发出并写入历史。附件无法离线排队，并会说明原因。托盘「离线消息队列」和主窗口顶栏可看到条数。偏好设置可改为发送前询问。
9. 新文本消息会弹出托盘提示；工具提示显示「用户数 + 未读数」，隐身或有排队时附带提示。单击托盘可唤起未读会话。

10. 托盘「设置」→「局域网外广播地址」：可填单个广播地址，或起始/结束 IP，或 `192.168.2.0/24` 这类 CIDR。保存后周期性入网会向范围内每个地址单播探测（单段最多 1024 个）。这不是中心服务器。
11. 主窗口输入文字后点「全体广播」，或托盘「向所有在线好友广播」。只发给当前在线或离开的好友，并带上广播标志；灰色离线不入队。对端会话里会看到「[广播]」前缀。
12. 会话里勾选「封装」再发送。对端气泡显示「密封信件」，点击后才出现正文，并回开封确认。带附件的密信仍可用原来的接收窗口拆开，正文同样进会话。
13. 与飞秋 2013 互通时传输编码保持 GBK。对方入网包若带 UTF-8 能力位，之后发给对方的文本改为 UTF-8。本端入网包宣告可收 UTF-8 和剪贴板附件。
