# QIpMsg

[![Build](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml/badge.svg)](https://github.com/foxwolf/qipmsg/actions/workflows/build.yml)

QIpMsg 是 Linux / Windows / macOS 下的 IP Messenger（飞鸽传书）客户端，兼容飞秋（Feiqiu / FeiQ）等同类局域网通讯工具。

当前版本：**2.7.0**

## 特性

- 局域网用户发现（昵称 / 分组/部门 / 主机 / IP / 在线状态 / 签名提示）
- 周期性在线刷新（飞秋 AutoRefresh）；上次用户灰色离线直至再次上线
- 按对端复用的持久聊天窗口，本地消息历史与全局查找
- 单聊与多选群发
- 本地讨论组（多选联系人命名保存，同一文本群发给各成员；非飞秋组播群协议）
- 文件 / 文件夹传输、目录进度、普通文件断点续传（飞秋 2013 / IPMSG TCP 十进制或十六进制命令）
- 大于 4GB 的文件：线缆允许处使用 64 位大小/偏移，续传与进度不截断
- 可配置 UDP 监听端口与网卡绑定（默认 2425 / 任意 IPv4，绑定失败软失败）
- 自动接收、默认保存目录、重名改名；聊天窗口拖放附件
- 窗口抖动、截图发送；会话气泡内联图片预览（点击打开原图）
- 工具栏基础 Unicode 表情包；飞秋 `/微笑` 一类口令在本端渲染为表情
- 系统托盘、未读计数与气泡通知
- 离开 / 自动回复（冷却、BR_ABSENCE）
- 本地备注昵称（`peers.json` 的 `memo`，树与会话标题用备注，资料卡保留真名）
- 联系人搜索支持拼音首字母与常见字全拼
- 隐身 / 隐藏模式（不回复发现，托盘可切换；无服务器，尽力而为）
- 离线消息队列（`offline_queue.json`，对方上线后按序发送；附件不入队）
- GBK 默认传输编码，可切换 UTF-8；解码失败时回退
- 界面默认简体中文（嵌入 `qipmsg_zh_CN.qm`；中文系统语言优先，其它环境回退中文）
- 现代浅色会话界面（WeChat / Slack-lite / Fluent）：主窗口头像与搜索、圆角联系人、聊天气泡、对方资料卡片
- 飞秋式联系人树（分组、搜索、个性签名、在线数、黑名单）与会话对方资料

## 试用 2.7.0

1. 启动后为简体中文浅色界面。主窗口顶部是自己的圆角头像、昵称、在线状态与个性签名；联系人按「我的好友 / 对方未分组好友 / 讨论组 / 部门组 / 自己 / 黑名单」分组。灰色用户来自 `~/.qipmsg/peers.json`，上线后恢复颜色。
2. 顶部「搜索好友 / 拼音」可按昵称、主机、登录名、备注、IP 过滤，并支持拼音首字母（如「张三」→ `zs`）与常见字全拼（如 `zhang`）。右键「设置备注」写入本地备注；树与会话标题显示备注，右侧资料「昵称」仍为对端真名。多选至少两名联系人后右键「创建讨论组」，组名与成员键（user@host/ip）保存在 `~/.qipmsg/discussions.json`。双击讨论组打开本地群发窗口；回复仍走一对一会话。这是本地多发 UX，不是飞秋组播聊天室协议。
3. 会话为气泡卡片：左侧收到、右侧发出。工具栏：发送文件/文件夹、表情、窗口抖动、截图、查找；远程/语音/共享/空间仍禁用，悬停提示「暂未实现」。右侧对方资料显示头像、状态、签名、真实昵称与主机/登录/分组/IP。发送或接收 png/jpg/gif/bmp/webp 后气泡内显示缩略图，点击打开原图。Ctrl+V 可粘贴剪贴板图片为附件。历史 JSONL 可带 `img` 字段。
4. 托盘或会话「查找历史」搜索全部 `history/*.jsonl`。
5. 托盘「设置」→「详细」→「文件」：续传、自动接收、重名改名、默认接收目录。同页「网络」可改 UDP/TCP 监听端口与绑定网卡（更改后需重启）。昵称框可填个人签名。
6. 托盘「离开 → 离开/自动回复」，或在偏好设置中填写回复内容与冷却秒数。收到普通消息时按对端冷却自动回复一次（抖动消息不自动回复）。
7. 托盘「离开 → 隐身/隐藏模式」或偏好设置勾选隐身：本机不再广播 `BR_ENTRY`/`BR_ABSENCE`，也不回复 `ANSENTRY`；进入隐身时先发 `BR_EXIT`。已知道你 IP 的对端仍可发消息（无中心服务器，无法对全网真正隐身）。
8. 对灰色/离线好友发文本会进入会话「离线队列」（可取消单条或清空）。对方再次入网后按顺序发出并写入历史。附件无法离线排队。托盘「离线消息队列」可查看全部待发。偏好设置可改为发送前询问。
9. 新文本消息会弹出托盘提示；工具提示显示「用户数 + 未读数」，隐身或有排队时附带提示。单击托盘可唤起未读会话。

密信与带附件的消息仍走原来的接收窗口；打开密信后文本会写入对应会话历史。飞秋组播群协议、群共享、群公告、完整聊天室同步，以及自定义表情、插件、文件共享服务、语音、公钥加密、换肤、NSIS 打包等见 [ROADMAP.md](../ROADMAP.md)。
