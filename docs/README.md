# QIpMsg

QIpMsg 是 Linux / Windows / macOS 下的 IP Messenger（飞鸽传书）客户端，兼容飞秋（Feiqiu）等同类局域网通讯工具。

当前版本：**2.0.0**

## 特性

- 局域网用户发现（昵称 / 分组 / 主机 / IP）
- 单聊与多选群发
- 文件 / 文件夹传输与进度显示
- 系统托盘与消息通知
- 消息历史日志
- GB2312/GBK/UTF-8 编码切换，适配中文局域网环境
